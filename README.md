# -Ethernet-64b-66b-Physical-Coding-Sublayer-PCS-
Designed and implemented the transmit and receive data path of an Ethernet 64b/66b Physical Coding Sublayer. (PCS) using System Verilog. The design includes a 64b/66b encoder, a bit-serial self-synchronous LFSR-based scrambler, descrambler, and decoder. Verified the design using a reusable UVM environment with constrained random testcases .
